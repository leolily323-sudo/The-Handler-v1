# Handler v1 public docs

This repository has two kinds of material:

1. frozen implementation and historical records under `Handlerv1/`
2. public-facing docs, examples, and maintainer tooling at the repository root

## Public-facing layout

- `README.md` — quick-start onboarding for new developers and reviewers
- `docs/` — deeper project evidence, maturity notes, and application-prep material
- `examples/` — verified, local-only demonstrations
- `.github/ISSUE_TEMPLATE/` — issue intake for bugs and enhancement requests
- `SECURITY.md` — responsible disclosure process
- `CONTRIBUTING.md` — contributor expectations
- `ROADMAP.md` — project direction and constraints

## Historical / authoritative records

The following remain in `Handlerv1/` and should not be treated as casual documentation:

- `Handlerv1/00-Project-Law-and-Session-Transition.md`
- `Handlerv1/HANDLER-V1-FREEZE-AND-VERIFICATION.md`
- `Handlerv1/Handler Blueprint v1.txt`
- `Handlerv1/Handler_v1_FREEZE_CANDIDATE.zip`

These are retained as design history, freeze evidence, and project law records.

## Documentation handling guidance

The public docs in this repository are intentionally easier to navigate than the historical architecture bundle. Auxiliary docs should describe the current project posture, local setup, issues, and evidence without altering frozen behavior or historical records.
