# Handler v1: public project roadmap

This roadmap is a planning document, not an authorization to change frozen architecture.

## Current

- Published source for deterministic command validation, authorization, idempotency claims, external-effect mediation, and typed outcomes
- Regression tests and a GitHub Actions workflow
- In-memory demonstration adapters
- Historical freeze-candidate architecture and audit records

## Near term

1. Confirm a clean installation and test run on GitHub Actions.
2. Improve first-time developer onboarding and verified example usage.
3. Publish current verification evidence linked to the exact commit and test run.
4. Add responsible security-reporting guidance and issue templates.

## Future proposals, subject to architectural approval

- Production-oriented adapter reference implementations
- Integration examples with external agent frameworks
- Distribution/release automation and version compatibility guarantees
- Independent implementation audit and threat-model publication

## Not claimed

No broad production deployment, external adoption metrics, enterprise support, or production security certification is claimed.
