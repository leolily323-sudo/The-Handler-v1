# Contributing

Thanks for your interest in contributing to Handler v1!

How to run tests locally

- Create a virtual environment: python -m venv .venv
- Activate it: source .venv/bin/activate  (or .\ .venv\Scripts\activate on Windows)
- Install dev deps: pip install -r requirements-dev.txt
- Run tests: pytest

Guidelines

- Keep changes focused and small; open a PR against the main branch.
- Run the test suite and linters before opening a PR.
- Document any public API changes in README and add tests for bug fixes.
